# 新用户使用指南

> 从安装到导出第一支演示视频，约 15 分钟走完全部流程。

本指南面向第一次使用 Recordly 的用户，带你完成一次完整的「录制 → 剪辑 → 导出」流程，并介绍日常使用中最常用的功能与快捷键。安装方式的完整说明见 [README](https://github.com/devcxl/recordly#安装)。

## 安装与启动

### 使用分发版（推荐）

| 平台 | 安装方式 |
|------|----------|
| Arch Linux | 从 [GitHub Releases](https://github.com/devcxl/recordly/releases) 下载 `.pkg.tar.zst`，执行 `sudo pacman -U ./recordly-*.pkg.tar.zst` |
| Debian / Ubuntu | 下载 `recordly_*.deb`，执行 `sudo dpkg -i recordly_*.deb` |
| Windows | 下载 `recordly.exe`，双击直接运行 |
| macOS | 下载 `recordly-macos.zip`，解压后将应用拖入 Applications |

### 从源码运行

需要 Python 3.10+ 与 FFmpeg：

```bash
git clone https://github.com/devcxl/recordly
cd recordly
pip install -e .
recordly          # 或 python main.py
```

::: warning 缺少 FFmpeg？
如果启动时弹出「缺少系统依赖」警告，请先安装 FFmpeg：macOS `brew install ffmpeg`，Linux `sudo apt install ffmpeg`，Windows `choco install ffmpeg`，或从 [ffmpeg.org](https://ffmpeg.org/download.html) 下载。
:::

## 首页导览

启动后首先看到**首页**，所有已保存的项目以卡片网格展示，按修改时间从新到旧排列：

- **🎬 开始录制**：开始一次新的屏幕录制。
- **📂 打开项目**：从文件选择器打开一个已有的 `project.json` 工程文件。
- **项目卡片**：单击打开项目进入编辑器；**双击卡片上的名称**可就地重命名（回车确认）；右键卡片选择「删除」（会弹出二次确认，删除不可恢复）。
- 空状态提示「还没有项目，开始录制吧！」——第一次使用时点「开始录制」即可。

## 第一次录制

1. 在首页点击 **🎬 开始录制**，确认弹窗提示后录制开始。
2. Recordly 窗口会**最小化到系统托盘**，随后开始录制（约半秒准备时间）。
3. 录制内容为**整个主显示器画面**，同时采集**麦克风**与**系统声音**两路音频。
4. 录制完成后，通过**系统托盘图标**右键选择 **■ 停止录制**。
5. 录制结束会自动保存项目，并**自动打开编辑器**进入剪辑。

::: tip 托盘菜单
系统托盘图标右键菜单包含：**⬤ 开始录制**、**■ 停止录制**、**显示窗口**、**退出**。录制中只有「停止录制」可用，平时只有「开始录制」可用。
:::

::: warning 关闭窗口 ≠ 退出
点击窗口的关闭按钮只是把应用**隐藏到系统托盘**（会弹出气泡提示），录制不会停止。要彻底退出，请使用托盘菜单的「退出」。
:::

## 编辑器界面导览

录制完成（或从首页打开项目）后进入编辑器，从上到下分为四个区域：

| 区域 | 内容 |
|------|------|
| **工具栏** | 撤销 ↩ / 重做 ↪、播放控制（⏪ ◀ ▶/⏸ ▶ ⏩）、帧数与时间码、📤 导出、✂ 裁剪模式、🎵 添加额外音频 |
| **预览区** | 当前帧的画面预览，也是缩放区域与裁剪框的编辑场所 |
| **时间线** | 视频轨、音频轨（麦克风/系统音频）、缩放轨与额外音频轨，所有剪辑操作在这里完成 |
| **状态栏** | 显示「● 准备就绪」等当前状态 |

菜单栏提供三个菜单：

- **文件**：保存、导出、返回首页、设置、退出
- **编辑**：撤销 / 重做（显示即将撤销的操作名）
- **帮助**：反馈（打开 GitHub Issues）、关于

## 时间线剪辑

### 基础操作

- **移动播放头**：单击或拖动时间线顶部的标尺；单击空白处也会移动播放头并取消选中。
- **快速播放**：**双击时间线空白处**，播放头跳到该位置并立即开始播放。
- **移动片段**：按住片段主体拖拽。音频片段可以在两条音频轨之间跨轨拖动，同轨拖动会自动防止重叠。
- **裁剪片段（Trim）**：把鼠标移到片段左/右边缘，光标变为 ⇔ 后拖动即可裁剪，片段最短 0.5 秒。
- **缩放时间线**：按住 **Ctrl + 滚轮** 以鼠标位置为中心缩放视图；普通滚轮横向滚动。
- **吸附对齐**：拖动视频片段时会自动吸附到播放头和其他片段的边缘，出现金色虚线对齐线。

### 多选与右键菜单

- 按住 **Ctrl 单击** 可把片段加入/移出多选，多选后可整体拖动或批量删除；右键菜单中有「全选」「清除选中」。
- 在片段上右键，常用菜单项：

| 菜单项 | 作用 |
|--------|------|
| 拆分 | 在播放头处把片段一分为二 |
| 速度 | 0.25x – 2.0x 变速 |
| 音量 | 静音 / 50% / 100% / 150% |
| 补录音频 | 仅麦克风轨：重新录制这段配音（见下文） |
| 删除 | 删除选中片段 |

### 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Space` | 播放 / 暂停 |
| `X` | 在播放头处切割 |
| `S` | 切割选中的片段 |
| `Delete` / `Backspace` | 删除选中片段 |
| `I` | 裁剪入点（删掉播放头之前的部分） |
| `O` | 裁剪出点（删掉播放头之后的部分） |
| `←` / `→` | 片段左移 / 右移 0.5 秒 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |

所有快捷键都可在 **文件 → 设置 → 快捷键** 中修改，支持冲突检测与一键恢复默认。

## 速度与音量

- **变速**：右键片段 →「速度」→ 选择 0.25x / 0.5x / 1x / 1.5x / 2x。
- **调音量**（三种方式任选）：
  1. 音频片段**左侧内嵌的竖向迷你滑条**：底部 0%、中部 100%、顶部 200%，直接拖动；
  2. 选中片段后底部的 **Inspector 属性面板**：「静音」按钮 + 「音量」滑块（0–200%）；
  3. 右键片段 →「音量」子菜单快速选择。
- 音量非 100% 时片段标签会显示如 `[150%]`。所有音量与变速操作均可撤销/重做。

## 音频进阶

### 双音频轨道

每次录制会自动生成两路音频轨道：**麦克风**（绿色）与**系统音频**（青色），两路始终同时采集。导出时会自动混合。

### 补录旁白

对旁白不满意时不必重录整段视频：右键**麦克风轨**上的片段 →「补录音频」→ 在弹窗中「开始录音」，说完点「结束录音」。补录完成后原片段会自动静音，新音频插在原位置，整体算一步撤销。

### 添加背景音乐

点击工具栏 **🎵 添加额外音频**，选择 MP3 / WAV / AAC / M4A / FLAC / OGG 文件，音频会从**当前播放头位置**插入一条「额外音频」轨道。

## 智能缩放

在「缩放」轨道（橙色）的空白处**双击**或右键选择「添加缩放块」，即可创建一个默认 2 秒的缩放片段：

- 创建或选中缩放块后，预览区出现蓝色的**「缩放区域」框**——拖动它移动位置，拖动四角调整大小，播放到该时间段时画面会平滑放大到这个区域。
- 默认框大小为画面的 50%，可在 **文件 → 设置 → 缩放** 中调整（10%–90%）。

## 光标特效与画面裁剪

- **光标特效**：在 **文件 → 设置 → 光标** 中配置光标大小（16–96）、明暗主题（dark/light）、样式（圆点 / 圆环 / 聚光 / 经典箭头）以及鼠标拖尾开关。鼠标点击时的蓝色涟漪效果默认开启。
- **画面裁剪**：点击工具栏 **✂ 裁剪模式**，预览区出现蓝色裁剪框（框外变暗），拖动四条边调整保留区域；再次点击 ✂ 退出。裁剪结果在导出时生效，也可在导出对话框中按固定比例中心裁剪。

## 导出视频

点击工具栏 **📤 导出**（或菜单 文件 → 导出），在「导出视频」对话框中配置：

| 选项 | 说明 |
|------|------|
| 导出格式 | MP4（H.264）或 GIF |
| 分辨率 | 原始 / 2160p (4K) / 1440p (2K) / 1080p (Full HD) / 720p (HD) / 480p (SD) / 360p / 自定义 |
| 宽高比 | 原始 / 16:9 / 9:16 / 1:1 / 4:3 / 4:5 / 16:10 / 10:16 |
| 画面裁剪 | 不裁剪 / 自由裁剪（需先开启 ✂ 模式）/ 按比例中心裁剪 |
| 质量 | 原始 (100%) / 高 (90%) / 好 (75%) / 中 (60%)，仅 MP4 |
| 帧率与码率 | MP4 帧率 5–120 FPS（默认与项目一致）、码率 1–100 Mbps（默认 10）；GIF 帧率 5–30、可勾选循环播放 |
| GPU 硬件编码 | 支持 NVIDIA NVENC 加速（仅 MP4，未检测到可用 GPU 时自动不可选） |

点「选择保存路径...」→「导出」，进度条走完后会提示保存位置与文件大小。导出在工作线程进行，中途可取消。

::: tip 想要更小的文件？
录制默认 30 FPS。教程类演示视频导出为 720p + 「好 (75%)」质量通常体积只有原来的几分之一；做动图就选 GIF 格式并把 GIF 帧率调低。
:::

## 项目管理与保存

- **保存位置**：所有项目保存在 `~/Recordly/projects/` 下，每个项目一个独立目录（帧数据、双路音频与 `project.json` 工程文件）。
- **自动保存时机**：录制结束时自动保存一次；**之后的剪辑修改不会自动保存**，请记得通过菜单 **文件 → 保存**（或从首页重新进入前）手动保存。
- **默认帧率**：在 **文件 → 设置 → 通用** 中调整（10–120 FPS，默认 30），录制中修改会在下次录制生效。
- **异常恢复**：应用崩溃后再启动会自动清理残留临时文件；录制异常结束时，只要已捕获到画面，项目就会被保留并提示「录制异常结束，项目已保留」，可从首页重新打开。

## 常见问题（FAQ）

**Q：点了「开始录制」后窗口不见了，怎么停止录制？**
窗口最小化到了系统托盘。右键托盘图标选择「■ 停止录制」即可；也可以先「显示窗口」再操作。

**Q：能只录屏幕的一部分吗？**
当前版本录制整个主显示器画面，暂不支持区域录制；导出时可以用 ✂ 裁剪模式或按比例裁剪去掉多余部分。

**Q：麦克风和系统声音能只录一路吗？**
两路音频在录制时始终同时采集。不需要的一路可以在剪辑时静音（右键 → 音量 → 静音），导出时自动混合。

**Q：我剪辑了半天，改动保存了吗？**
录制结束会自动保存一次，之后的剪辑修改需要手动 **文件 → 保存**。修改过的项目建议每次大改后保存一次。

**Q：导出时「GPU 硬件编码 (NVENC)」灰掉无法勾选？**
说明未检测到支持 NVENC 的 NVIDIA GPU 或编码器，使用默认 CPU 编码即可，只是导出速度慢一些。

**Q：找不到文字标注、箭头、摄像头画中画？**
这些功能尚未在当前版本开放，会在后续版本中提供。

**Q：软件出问题想反馈？**
菜单 **帮助 → 反馈** 会打开 GitHub Issues 页面，欢迎附上复现步骤与项目目录中的 `project.json`。
