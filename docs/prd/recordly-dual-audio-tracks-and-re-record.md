# 双音频轨道编辑与麦克风补录 — PRD

**日期：** 2026-08-10
**状态：** Confirmed
**关联：** Flow #125

---

## 1. 背景与问题

录制时麦克风（`audio_mic.wav`）与系统音频（`audio_system.wav`）已分离采集、分离保存，但加载后即被混音为单一音频：

- 时间线只有一条 `audio` 轨（标记为"麦克风"），系统音频在时间线上不可见、不可编辑；
- 内置 `audio` 轨的裁剪/删除/移动/音量操作**完全不生效**——预览与导出始终使用混音结果，只有 `audio_extra`（额外音频）轨的编辑生效；
- 无法对某段麦克风声音进行局部补录。

## 2. 目标

1. **双音频轨道展示**：时间线展示两条内置音频轨——麦克风（`audio`）与系统音频（`audio_system`），独立 clip + 波形。
2. **双轨编辑生效**：两条内置轨的裁剪/删除/移动/音量编辑必须真实作用于**预览播放**与**导出**（与现有 `audio_extra` 轨同等的编辑能力）。
3. **麦克风补录**：对 mic 轨的任意 clip 发起补录 → 弹出独立录音窗口 → 结束后录音自动保存为项目内 wav，并作为新 clip 插入 mic 轨对应时间段；原段落静音保留（不删除），新录音替换声音。
4. **范围**：system 轨与 mic 轨同样支持编辑（裁剪/删除/音量）；补录只针对麦克风。

## 3. 用户故事

### US-1 双轨展示
作为用户，我在录制完成后看到时间线有两条音频轨：麦克风（带 mic 波形）与系统音频（带 system 波形），各自有一个覆盖全片段的 clip。

### US-2 双轨编辑生效（预览）
作为用户，我删除/裁剪/移动 mic 轨某段、或将某 clip 音量调为 0 后，**点击播放**时能听到对应变化（删除段无麦克风声音，system 轨不受影响）。

### US-3 双轨编辑生效（导出）
作为用户，我对两条内置轨做的编辑（裁剪/删除/移动/音量）在**导出视频**中与预览一致地生效。

### US-4 麦克风补录
作为用户，我右键 mic 轨任意 clip 选择"补录音频"，在弹出的独立窗口点"开始"录音、点"结束"停止；录音结束后自动保存为项目内 wav 并作为新 clip 出现在 mic 轨对应时间段，预览/导出中该时间段听到的是新录音，原麦克风声音被静音（但不删除，撤销后可恢复）。

### US-5 补录失败/取消无残留
作为用户，我在补录窗口直接关闭（取消）或录音失败时，时间线不发生任何变化（无新 clip、原 clip 原样），项目目录不残留录音文件。

### US-6 补录可撤销
作为用户，我撤销一次补录操作后，mic 轨恢复原状（新 clip 消失、原段落音量恢复），再重做则补录再次生效。

### US-7 旧项目兼容
作为用户，我打开旧版本保存的项目：麦克风轨正常显示并可编辑；若该项目有系统音频（`source.audio_system`），时间线自动补出系统音频轨；补录 clip 保存后再次打开依然存在且可编辑。

## 4. 验收标准

### AC-1（双轨展示）
- 新录制项目时间线含三条音频相关轨：`audio`（麦克风）、`audio_system`（系统音频）、以及用户自行添加的额外音频轨（保持现状）。
- mic 轨与 system 轨的 clip 均绘制各自源音频的波形（波形数据来自对应 wav，而非混音）。
- 无麦克风或无语系统音频的录制，对应轨存在但无音频（clip 显示存在，波形为空，导出无对应声音）。

### AC-2（编辑生效：预览）
- 对 mic 轨执行：删除某 clip、裁剪（拆分+删除）、移动 clip、音量 0% —— 预览播放时麦克风声音按编辑结果变化；system 轨声音不受 mic 轨编辑影响。
- 对 system 轨执行同样的编辑 —— 预览时系统声音按编辑结果变化；mic 轨不受影响。
- 双轨编辑叠加时，预览听到的是两轨编辑结果的混音。

### AC-3（编辑生效：导出）
- 与 AC-2 相同的编辑组合，导出视频的音频与预览一致。
- **无任何编辑时，导出音频与旧版本逐样本等价**（不引入音量衰减、不改变采样率语义）。

### AC-4（补录成功）
- 右键 mic 轨 clip → "补录音频" → 弹窗录音 → 结束：
  - 项目目录出现 `re_record_<时间戳>.wav`；
  - mic 轨出现新 clip（source 指向该 wav），覆盖补录时间段；
  - 被补录的原始 clip 段落静音（volume=0），clip 仍在（未删除）；
  - 预览与导出中该时间段听到新录音；
  - 录音时长短于目标区间时，剩余部分静音；长于目标区间时，截断到目标区间右边界。
- 补录后保存项目，重新打开：补录 clip 与静音状态完整恢复。

### AC-5（补录失败/取消）
- 补录窗口取消/关闭：时间线无变化、项目目录无新 wav 文件。
- 录音返回 0 秒数据：视为失败，同样无变化、无残留。
- wav 写入失败：提示错误，无 clip 插入、无残留文件。

### AC-6（撤销/重做）
- 补录为**单个撤销单元**：一次 Ctrl+Z 后 mic 轨完全恢复（新 clip 消失、原 clip 音量恢复）；Ctrl+Shift+Z 重做后补录再次生效。

### AC-7（旧项目兼容）
- 打开 v1.1.0 旧项目：
  - 原有 `audio` 轨作为麦克风轨正常编辑，编辑结果作用于导出/预览；
  - `source.audio_system` 存在时自动补出 `audio_system` 轨（全时长 clip，指向 `audio_system.wav`）；
  - 保存后再打开，补齐的轨道完整保留（幂等）。
- 打开项目时无 schema 校验错误（未知字段拒绝逻辑不误伤）。

## 5. 非目标（本轮不做）

- 内置音频轨的速度（speed）编辑与变速导出（速度菜单仍只对 video 轨显示）。
- mic 轨与 system 轨之间的跨轨拖拽。
- 补录录音的波形实时预览、降噪、增益调整。
- 撤销补录后自动删除已生成的 wav 文件（文件作为项目资产保留）。
- 系统音频的补录/重录。
- 移动 clip 时的时间线吸附增强（保持现状）。
