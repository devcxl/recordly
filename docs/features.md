# 功能特性详解

Recordly 专为软件演示、教程教学与交互汇报设计，将「高品质屏幕录制」与「演示专用轻量剪辑」紧密融为一体，帮助你在几分钟内产出媲美专业团队制作的视频与动图。

---

## 高清流畅的屏幕采集

### 低硬件负担与高流畅度
- **全屏与高分屏优化**：无论是在 4K 高分辨率显示器还是笔记本屏幕上，均能以极低 CPU 占用流畅录制整个桌面。
- **自定义帧率**：支持 10 到 120 FPS 自由设定。教程演示使用默认的 30 FPS 即可获得兼顾流畅度与体积的最佳平衡。
- **托盘静默运行**：点击开始录制后，主界面自动收缩至系统托盘，不遮挡屏幕任何内容，准备就绪后平滑开始。

---

## 醒目光标特效与轨迹平滑

### 让观众看清每一次操作
- **点击波纹光环**：鼠标每次点击都会在落点激起醒目的扩散波纹，无论左键点击按钮还是右键菜单，观众都能一眼看清。
- **轨迹平滑插值**：自动优化鼠标快速拖动或甩动时的路径，消除鼠标丢帧抖动的眩晕感，使演示呈现沉浸的电影质感。
- **光标外观个性化**：在设置中支持调节光标尺寸（16 至 96 像素）、深浅色主题，以及在经典箭头、高亮圆点和聚光灯效果之间随时切换。

---

## 独立双音轨与「原地补录」旁白

### 说错一句话，不用推倒重录整段
- **麦克风与系统音分轨录制**：麦克风讲解人声与电脑系统声音（软件音效、背景音乐）分别保存为独立轨道，互不串音。
- **波形可视化与音量调节**：时间线上清晰展示两路音频的真实波形，支持 0% 到 200% 的连续增益滑块调节，或者直接一键静音某一路。
- **革命性的旁白补录功能**：录制完 10 分钟视频，发现其中一句口误或环境有杂音？在时间线上右键点击该音频片段选择「补录音频」，录制一段新的旁白原位替换，原片段自动静音，彻底告别反反复复重新录制的痛苦。
- **支持导入背景音乐**：点击工具栏添加外部音频，可将 MP3、WAV、AAC、FLAC 等背景伴奏轻松叠加到演示中。

## 演示专用多轨时间线

### 告别专业剪辑软件的复杂学习曲线
- **即拖即剪（Trim）**：鼠标移动到视频或音频片段边缘，光标变为调整图标后拖拽即可精确修剪掉多余的停顿与无声片段。
- **播放头一键拆分（Split）**：快捷键 `X` 即可在当前播放位置一刀两断，随心所欲删除废话片段。
- **智能吸附对齐（Snap）**：移动片段时自动吸附到相邻边缘或播放头，并亮起对齐辅助线，防止片段间产生黑屏间隙。
- **无级变速快进（Speed）**：对于代码安装、文件下载等耗时等待的枯燥过程，支持右键一键设置为 1.5x 或 2.0x 快进。
- **多选批量操作与无限撤销**：按住 `Ctrl` 框选多段内容即可整体拖移或一并删除；所有操作均支持 `Ctrl+Z` 撤销与 `Ctrl+Shift+Z` 重做，尽情尝试无需担心误操作。

## 智能镜头运镜与局部缩放

### 观众看不清细小代码？镜头推近放大
- **专属缩放轨道（Zoom Track）**：在缩放轨双击即可添加一段运镜缩放块。
- **可视画框圈定重点**：在预览画布上拖拽蓝色虚线框，圈选你想要观众聚焦的区域（如某行关键代码、特定表单字段或菜单栏）。
- **平滑推近运镜**：播放到该时段时，画面会自动以平滑运镜放大该区域，在片段结束时优雅回到全景，观感极具质感。

---

## 全渠道尺寸与高速多格式导出

### 从社交短视频到 GitHub 动图全搞定
- **主流社交画幅**：一键切换 16:9（B站、YouTube）、9:16（移动端小红书、抖音）、1:1（方形展示）或 4:3 比例，支持画面中心自动填充裁剪或自由框选裁剪。
- **超清 4K 与 MP4 导出**：支持 4K (2160p)、2K (1440p)、1080p (Full HD) 等多种清晰度与码率设定。
- **精美小巧的 GIF 动图**：直接输出适合嵌入 GitHub README、技术博客与 Pull Request 的循环流畅 GIF，并可微调帧率控制文件大小。
- **GPU 硬件编码加速**：支持 NVIDIA NVENC 硬件加速，大幅缩短视频导出渲染耗时，减少电脑发热与卡顿。

## 本地持久化与工程安全

- **录完即建独立工程**：每次录制完成自动在电脑本地创建独立工程目录，原始帧和音频完整归档，方便日后随时从首页重新打开继续二次剪辑。
- **断电与崩溃保护**：工程文件写入采用原子化安全保存；如录制过程中电脑意外断电或被强制终止，只要采集到了有效画面，再次启动时应用会自动挽救已有素材并安全恢复。
- **100% 隐私与离线**：不依赖任何网络连接，无需登录账号，你的每一帧画面和每一句声音完全保存在你自己的硬盘上。
